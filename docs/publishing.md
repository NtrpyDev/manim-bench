# Publishing Results

Reports generated by `manimbench report` are static and can be hosted directly
or used as data input for a richer future `manimbench.site` frontend.

Publishable reports should include:

- `index.html` landing page.
- `data/results.json`.
- `data/models.json`.
- `data/tasks.json`.
- `data/manifest.json`.
- `report.md`.
- `models/*.html`.
- `tasks/*.html`.
- Run manifest with prompt, suite, task, sandbox, and runtime hashes.
- Links or hosted paths for rendered videos and logs where appropriate.

Official public results should come from the container sandbox with network
disabled and resource limits recorded.
