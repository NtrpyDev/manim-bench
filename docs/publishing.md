# Publishing Results

Reports generated by `manimbench report` are static and export site-ready data
under `reports/<run_id>/data/`.

Publishable reports should include:

- `index.html` landing page.
- `data/results.json`.
- `data/models.json`.
- `data/tasks.json`.
- `data/manifest.json`.
- `report.md`.
- `models/*.html`.
- `tasks/*.html`.
- Run manifest with prompt, suite, task, sandbox, and runtime hashes.
- `data/leaderboard.json` schema `0.6.0`, including capability score,
  pass rate, coverage, render success, and failure buckets.
- Links or hosted paths for rendered videos and logs where appropriate.

Use `manimbench publish` to copy report data and videos into the separate site
repository. Official public results should come from the container sandbox with
network disabled, resource limits recorded, and a Docker image digest present in
the run manifest.
