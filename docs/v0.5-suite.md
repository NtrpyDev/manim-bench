# V0.5 Suite

The default v0.5 suite is:

```text
benchmarks/v0.5/suite.yaml
```

It contains six focused tasks:

- `coordinate_system_animation`
- `derivative_motion_story`
- `matrix_transformation_grid`
- `geometric_area_proof`
- `probability_distribution_simulation`
- `fourier_series_decomposition`

Contract:

- One Python file per task at `outputs/<model>/<task_id>.py`.
- Each file must define `class MainScene`.
- Render target is Manim Community Edition at 60 FPS.
- Task runtime limit is 120 seconds.
- Official runs use the container sandbox.

The previous public suite remains intact:

```bash
manimbench --suite benchmarks/v0.4/suite.yaml list-tasks
```

Run manifests record the master prompt hash and task file hashes for the suite
used in the run.
