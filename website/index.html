Methodology

One shared prompt, six focused submissions, identical sandbox. V0.4 scores model behavior that is hard to fake with source keywords alone.

Task Coverage

Each model solves six separate ManimCE tasks: layout basics, derivative graphing, matrix transformation, measured geometry, dice probabilities, and Fourier heat equation intuition.

Output Contract

Every task maps to one file named outputs/<task_id>.py. Each file must import ManimCE and define a primary scene class named MainScene.

Sandbox Render

Official runs use the container backend with network disabled, resource limits, 60 FPS rendering, and a 120 second per-task runtime cap.

Source Checks

The scorer parses Python with AST checks. Comments and unused strings do not satisfy required constructs, and placeholder scenes are capped even when they render.

Visual Sanity

Rendered frames are sampled for blank output, foreground clutter, edge clipping, low contrast, and dense regions that often indicate label collisions.

Usage Accounting

Reports include generation time, input tokens, output tokens, total tokens, and estimated USD cost from the configured model registry.

Run V0.4

V0.4 is file-backed. Generate one ManimCE file per task, place the files in an output folder, then run the launcher.

  1. python -m pip install -e ".[dev,render]"
  2. Write six files under outputs/<model>/, named with the V0.4 task IDs.
  3. python start_benchmark.py
  4. Select the public suite, the model output folder, and the container sandbox for official runs.
Each output file must define one ManimCE MainScene. The default suite expects basic_manim_layout.py, calculus_derivative_graph.py, linear_algebra_transformation.py, geometry_measurement_diagram.py, probability_distribution.py, and advanced_math_explanation.py.
